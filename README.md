# FR_Hand_s_ts_B1 — 拇指与食指的一号触觉从板

`FR_Hand_s_ts_B1` 运行于 STM32F407VETx，MODBUS地址为0x01。motor0/1/2驱动拇指三个自由度，motor3驱动食指。拇指motor0/1共用NSS1触觉反馈并依次退让；motor2始终按无力角度控制；食指使用NSS2独立导纳。

上位机既可以通过 RS485/Modbus RTU 直连本从板，也可以经 `FR_Hand_m` 主板转发电机控制寄存器。

> 上位机控制模式、完整 Modbus 帧和参数调节方法请参阅 [导纳控制上位机指令说明](docs/Admittance_Control_Protocol.md)。

## 硬件与通信

| 项目 | 当前配置 |
|---|---|
| MCU | STM32F407VETx，Cortex-M4F，168 MHz |
| RTOS | FreeRTOS V10.3.1，CMSIS-RTOS V2 API |
| 电机 | 4 路直流电机，级联闭环控制 |
| 关节位置 | 4 路 ADC 霍尔传感器 |
| 触觉传感器 | 2个三维力传感器，对应拇指、食指 |
| 触觉接口 | SPI3：PC10/SCK、PC11/MISO、PC12/MOSI |
| 触觉片选 | NSS1/PA8：拇指；NSS2/PD1：食指；NSS3/PD2不使用并保持高 |
| CAN反馈 | CAN1，PA11/RX、PA12/TX，875 kbit/s，ID 0x20/0x21，默认各20 Hz |
| 微秒延时 | TIM13，为触觉传感器 SPI 时序提供延时 |
| 上位机通信 | USART1，RS485，Modbus RTU，230400 bit/s，8N1 |
| 调试输出 | USART2，230400 bit/s |
| Modbus 地址 | 由 `RS485_SLAVE_ADDR` 编译时配置；本文示例使用 `0x01` |
| 支持功能码 | `0x03`、`0x06`、`0x10` |

SPI3和TIM13在启动时初始化，只校准和注册两个传感器。独立采集任务以100 Hz采集ADC和启用的两路力，与电机使能、控制模式及CAN上报独立。Reg[18]默认0x000B；bit0或bit1开启拇指NSS1，bit3开启食指NSS2。

## 控制模式

控制模式由 `Reg[4]` 的高字节选择，低字节为输出使能：低字节为 `0` 时停止输出，非 `0` 时允许运行。

| 模式 | 说明 |
|---:|---|
| 1 | 正向输出轴角度控制；目标圈数位于 `Reg[0..3]` 高字节 |
| 3 | 反向输出轴角度控制 |
| 4 | 紧急停止并清零编码器 |
| 5 | 普通关节角度控制，目标角度采用四位压缩 BCD |
| 6 | 输出轴圈数导纳；motor0/1共用退让量顺序分配，motor2普通角度，motor3独立导纳 |
| 7 | 关节角度导纳；拇指先退motor0至5°附近再退motor1，推荐使用 |

### 模式 5 和模式 7 的角度格式

目标角度使用四位压缩 BCD，而不是普通十六进制数值：

```text
0x0050 =  5.0°
0x0300 = 30.0°
0x0555 = 55.5°
0x0900 = 90.0°
```

有效范围为 `5.0°～90.0°`。每个十六进制位都必须是 `0～9`；例如 `0x03AF` 是非法 BCD，固件会拒绝该目标并立即停止对应电机。模式 6 仍沿用原有的圈数/速度编码，不使用 BCD。

## 触觉导纳控制

当前实现提供两种触觉导纳模式：

- 模式6：拇指motor0/1共用一份导纳总退让圈数，先让motor0回到0圈附近，再把余量分给motor1；食指motor3独立退让。motor2从Reg[2]生成普通输出轴目标，不受力传感器失效影响。
- 模式7：拇指每周期只更新一次导纳，总退让量最多40°；先消耗motor0从基准到5°的可退量，实际反馈到达5°附近后再减小motor1目标。到位容差沿用位置环5个ADC码死区；例如基准30°/40°、总退让40°，最终目标5°/25°。motor2执行普通关节位置控制，motor3使用食指力独立退让。

控制周期为 `10 ms`，触觉力小于 `0.05 N` 时进入死区。当前默认导纳参数为：

| 寄存器 | 参数 | 上电值 | 实际值 |
|---:|---|---:|---:|
| `Reg[15]` | 接触刚度 `K_contact` | `0x0020`（32） | `0.032` |
| `Reg[16]` | 回弹刚度 `K_return` | `0x03E8`（1000） | `1.000` |
| `Reg[17]` | 虚拟阻尼 `B_damp` | `0x0010`（16） | `0.016` |

三个参数均按“寄存器值 × `0.001`”换算。上位机直连从板时，可使用以下指令一次写入默认值：

```text
01 10 00 0F 00 03 06 00 20 03 E8 00 10 D6 CB
```

## Modbus 快速示例

以下帧均已包含 Modbus CRC16，CRC 低字节在前。示例假设从机地址为 `0x01`。

### 四个关节以 30.0° 为基准启动模式 7

```text
01 10 00 00 00 05 0A 03 00 03 00 03 00 03 00 07 01 72 65
```

其中 `Reg[0..3] = 0x0300`，`Reg[4] = 0x0701`。

### 停止全部 PWM 输出

```text
01 06 00 04 00 00 C8 0B
```

### 回到 5.0° 并切换至普通关节角度模式

```text
01 10 00 00 00 05 0A 00 50 00 50 00 50 00 50 05 01 AF 73
```

自定义角度、参数以及经主板转发的完整示例见 [docs/Admittance_Control_Protocol.md](docs/Admittance_Control_Protocol.md)。

## 经 FR_Hand_m 主板控制时的限制

当前主板仅转发每块从板的 `Reg[0..4]`：

| 主板寄存器 | 转发目标 |
|---|---|
| `Reg[4..8]` | 从板 `0x01` 的 `Reg[0..4]` |
| `Reg[9..13]` | 从板 `0x02` 的 `Reg[0..4]` |

因此，经主板可以启动模式 6/7、设置目标角度和停止电机，但不能修改从板的 `Reg[15..17]` 导纳参数。修改参数时需要直连从板、调整固件默认值，或扩展主板转发协议。

## 安全行为与已知限制

- 拇指合力超过15 N时同时锁定motor0/1；食指超限只锁定motor3。模式6安全目标0圈，模式7安全目标5°，motor2不参与力锁定。
- 超限手指不会在外力下降后自动恢复；上位机必须重新写入 `0x0601` 或 `0x0701` 才能解除对应模式的拇指/食指锁定。
- 模式 7 的导纳最大退让量为 `40°`，关节目标被限制在 `5.0°～90.0°`。
- 编码器累计角度超过正负 60 圈时，固件停止对应电机。
- 系统检测到 12 V 主电掉电时会执行紧急停止，供电恢复后重新允许控制。
- 三路 `Fx`、`Fy`、`Fz` 和合力尚未映射到 Modbus 寄存器；上位机不能通过功能码 `0x03` 读取实时触觉力。
- 拇指传感器关闭、失效或超过50 ms时，motor0/1同时暂停；食指异常仅暂停motor3，motor2不检查触觉有效性。模式7四路仍依赖ADC有效性。
- 保留复制工程的四路霍尔标定端点；这些数值是否匹配一号板实际机构需重新确认。

## FreeRTOS 任务架构

| 任务 | 优先级 | 周期/触发方式 | 职责 |
|---|---|---|---|
| `vMotorControlTask` | Realtime | 10 ms | 四路电机闭环、共享导纳目标分配和PWM更新（不读SPI） |
| `vModbusCommTask` | High | DMA + IDLE 事件驱动 | Modbus RTU 帧解析和寄存器读写 |
| `vSensorProcessTask` | Normal | 10 ms | 四路ADC有限批次、两路SPI及反馈缓存发布 |
| `vCanTelemetryTask` | BelowNormal | 默认50 ms | 两条CAN缓存反馈，频率由MODBUS配置 |
| `vSystemMonitorTask` | Low | 当前250 ms | 通信超时、掉电保护、心跳和调试输出 |

共享的电机状态与 Modbus 寄存器由 `xMotorDataMutex` 保护。

## 电机与关节减速比实验

原减速比实验采集工具继续保留。当前系统监控任务每250 ms默认输出拇指motor0的数据帧（`Print_Motor_Status(0, 101)`），格式为`FF,关节角度,法向力/切向力,合力,FE`。下述CSV格式属于参数5的实验输出，使用对应工具前需切换调试输出：

```text
电机编号,电机累计圈数,关节角度
1,12.3456,37.20
```

使用串口实时记录数据、绘制曲线并拟合减速比：

```bash
pip install pyserial matplotlib numpy
python tools/plot_motor_reduction_ratio.py COM8 230400 --motor 1 --degree 3
```

默认串口为`COM8`，默认采用三次多项式，可通过`--degree 1～5`选择其他阶数。按`Ctrl+C`或关闭图表窗口停止采集，脚本会在`logs/`目录保存原始CSV、PNG图表和拟合结果TXT。

```text
电机圈数变化 = aₙxⁿ + ... + a₁x + a₀
局部减速比(x) = 360 × |d(电机圈数变化)/dx|
```

其中`x`为相对首个采样点的关节角度变化。拟合结果包含完整多项式系数、决定系数`R²`、有效角度范围和末点局部减速比。

脚本还会按照最佳拟合直线（BFSL）分析线性度，绘制关节角度对应的线性残差，并输出线性拟合`R²`、RMSE、最大绝对偏差和满量程线性度误差：

```text
满量程线性度误差 = 最大绝对线性残差 / 电机圈数满量程变化 × 100%
```

### 多输出限幅对比采集

当模式1或模式3的电机0目标为60圈，且输出限幅为20%、40%、60%、80%或100%时，固件会先输出：

```text
EXPERIMENT_START,电机编号,输出限幅百分比,模式
```

发送`Reg[0]=0x0064`以100%限幅返回零点时，固件输出`EXPERIMENT_STOP`，返回过程不会被记录。停止输出或进入模式4也会输出停止标志。使用中文采集脚本可以自动丢弃开始标志之前的波动数据，并连续记录五组实验：

| 实验限幅 | 60圈运动指令`Reg[0]` | 返回零点`Reg[0]` |
|---:|---:|---:|
| 20% | `0x3C14` | `0x0064` |
| 40% | `0x3C28` | `0x0064` |
| 60% | `0x3C3C` | `0x0064` |
| 80% | `0x3C50` | `0x0064` |
| 100% | `0x3C64` | `0x0064` |

```bash
python tools/多速度减速比数据采集.py COM8 230400
```

也可以自定义要比较的限幅和拟合阶数：

```bash
python tools/多速度减速比数据采集.py COM8 230400 --limits 20,40,60,80,100 --degree 3
```

每次收到新的开始标志都会建立独立实验段，并以该段第一条有效数据作为相对零点。第五档返回零点后脚本自动结束，也可以提前按`Ctrl+C`停止。输出包括原始数据CSV、指标汇总CSV、分析报告TXT、综合对比PNG，以及把五档局部减速比叠加在同一坐标系中的`五档速度减速比曲线_时间.png`。

## 推荐上位机操作顺序

1. 确认串口参数和从机地址。
2. 读取 `Reg[0..17]`，确认 Modbus 通信正常。
3. 直连从板设置 `Reg[15..17]`；初次测试建议保留默认参数。
4. 使用模式 5 将四个关节移动到安全基准位置。
5. 发送模式 7 启动帧并缓慢施加外力。
6. 调参时每次只修改一个参数，并提前准备停止帧。
7. 测试结束后将 `Reg[4]` 写为 `0x0000`。

首次联调前请完整阅读 [导纳控制上位机指令说明](docs/Admittance_Control_Protocol.md)，并确保机构留有足够的安全行程。

CAN角度/力上报及Reg[18..20]配置见[CAN反馈协议](docs/CAN_Telemetry_Protocol.md)。一号板本次改动仅完成源码实现与静态核对，未编译、未运行测试、未烧录；二号板此前的编译结果不代表本次一号板已编译通过。
