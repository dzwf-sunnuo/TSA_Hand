## 1. 可行性与控制边界

七个有效电机各使用两个16位寄存器，交错排列为 `[目标0, 模式0, 目标1, 模式1, …]`，共14个寄存器。每路目标编码仍由它自己的模式决定，各路使能也独立。可以同时令食指执行模式5、中指执行模式7，或让其余电机停止。

这里的14个寄存器只描述七路手指电机，不包括推杆、手腕、PID、导纳参数和反馈；这些仍有独立寄存器。主板一次接收，异步拆分为两个从板请求，不是两块板严格同时执行。

三块板的相关RS485链路均为230400/8N1。主板从站地址0x10；一号板0x01，二号板0x02。USART1保留应答；主板UART4沿用之前的静默Modbus接收，无控制应答，UART4遥测也保持原样。

## 2. 主板14寄存器映射

上位机使用功能码0x10，从主板零基地址 **0x0004** 连续写 **0x000E** 个寄存器，数据字节数 **0x1C**，请求总长37字节。

| 电机 | 主板目标 | 主板模式/使能 | 从板目标 | 从板模式/使能 |
|---|---|---|---|---|
| 拇指第一关节，B1 motor0 | 0x0004 | 0x0005 | 0x01:0x0000 | 0x01:0x0001 |
| 拇指第二关节，B1 motor1 | 0x0006 | 0x0007 | 0x01:0x0002 | 0x01:0x0003 |
| 拇指第三自由度，B1 motor2 | 0x0008 | 0x0009 | 0x01:0x0004 | 0x01:0x0005 |
| 食指，B1 motor3 | 0x000A | 0x000B | 0x01:0x0006 | 0x01:0x0007 |
| 中指，B2原motor1 | 0x000C | 0x000D | 0x02:0x0000 | 0x02:0x0001 |
| 无名指，B2原motor2 | 0x000E | 0x000F | 0x02:0x0002 | 0x02:0x0003 |
| 小指，B2原motor3 | 0x0010 | 0x0011 | 0x02:0x0004 | 0x02:0x0005 |

二号板原motor0已从PWM/编码器启动、控制循环、掉电恢复和Modbus控制入口移除；为了保留原ADC标定、CAN通道与硬件编号，内部数组仍保留四个硬件下标的存储跨度，motor0不再运行。三指触觉采集位仍是Reg[18]的bit1/2/3，默认0x000E，不改成bit0/1/2。

主板仅写某一对目标/模式、只写某个目标或模式均可，其余寄存器保持原值；分发任务发送受影响从板的完整8/6寄存器快照。连续相同模式不会反复重置其他电机导纳。多次快速主板写入可能合并成最新快照，不保证每个中间目标都下发。

## 3. 单电机模式与目标编码

模式/使能寄存器的高字节为模式，低字节0为停止、非0为使能。推荐启用值1；停止一条电机可将它的模式/使能寄存器写0x0000。

| 模式字示例 | 含义 | 目标编码 |
|---|---|---|
| 0x0000 | 停止当前电机输出 | 目标保存，不要求清零 |
| 0x0101 | 正向输出轴角度 | 高字节为圈数，低字节为原速度/输出限幅百分比 |
| 0x0301 | 反向输出轴角度 | 同上 |
| 0x0401 | 仅当前电机编码器清零并停止 | 不清其他电机 |
| 0x0501 | 普通关节角度 | 四位压缩BCD，单位0.1° |
| 0x0601 | 输出轴圈数导纳 | 高字节圈数，低字节限幅百分比 |
| 0x0701 | 关节角度导纳 | 四位压缩BCD，单位0.1° |

例如目标0x0064在模式1表示0圈、限幅100%，不是100°。模式5/7的0x0300才表示30.0°，0x0050表示5.0°。目标范围与保护沿用旧控制律，非法BCD停对应路。切换模式或启停清理该路PID历史，避免旧模式积分残留。

从板读取每周期全部目标及模式采用一次短临界区快照，不会将同一批次的目标和模式拼错。保护回写安全目标时检查寄存器是否仍匹配本周期快照，不覆盖通信任务刚提交的新命令。

## 4. 独立导纳与双拇指

二号板三个手指各自维护导纳与超力锁定，切换或清零某一路不会影响其他手指。超过15N时保持原安全回退目标：模式6为0圈，模式7为5.0°。

一号板两个拇指关节仍共享NSS1力样本。两者都启用相同导纳模式6或7时保留“第一关节先退到边界，第二关节再消耗余量”的原分配；两者模式不同或只有一者启用导纳时，启用导纳的关节使用各自独立积分，普通模式关节不被退让模型改写。模式6的圈数与模式7的度数不会混用。

同模式双拇指发生超力时仍作为耦合组锁定；食指模式与积分始终独立。motor2无物理触觉，模式6/7按无外力的普通目标处理。

为了连续快帧不每次清零积分，成组帧重复相同模式不触发重启。直接访问从板，用0x06单独重写该电机模式寄存器可重启/解除对应模式锁定；经主板复位导纳可先将该电机模式写0，确保从板已收到停止后再恢复6/7；过快连续写入可能合并而看不到中间的停用模式。若双拇指仍处于耦合锁定，需分别复位两者或一起停用再恢复。力仍超过15N时会再次锁定。

## 5. 配置地址迁移

| 位置 | 新地址 | 说明 |
|---|---|---|
| 从板三环PID | 0x0020～0x0028 | 原0x0005～0x000D不能继续作为PID参数，否则会影响新电机控制区 |
| 从板导纳K/B/阻尼 | 0x000F～0x0011 | 各板独立保持原地址，参数仍为本板公共配置 |
| 从板触觉位掩码 | 0x0012 | B1默认0x000B，B2默认0x000E |
| 从板CAN共同开关/频率 | 0x0013 / 0x0014 | 保持原地址 |
| 主板手腕许可/摆动控制 | 0x0028 | 原0x000E |
| 主板摆动周期 | 0x0029 | 原0x000F |
| 主板原两个预设存储值 | 0x002A / 0x002B | 原0x0010 / 0x0011，保留初始化值，不新增业务 |
| 主板UART4上报配置 | 0x001E～0x0021 | 保持原地址 |

主板和从板地址空间相互独立，例如主板Reg[40]是手腕控制，从板Reg[40]是速度环Kd。主板已有PID Reg[20..28]只是原存储接口，本次不新增PID参数跨板转发；配置从板PID应在从板总线上分别访问地址0x01/0x02。

## 7. 兼容性与构建

旧的四目标加公共模式帧已不兼容直接控制。主板内置旧预设动作表通过专用适配函数转换，二号板转换时丢弃原motor0。CAN全电机命令data[1..7]依次对应三个拇指自由度、食指、中指、无名指、小指，转成各自的模式后分发。

串口、CAN反馈字节布局、采集映射以及主板UART4的26字节遥测保持现有实现。七路手指不是七路都带独立触觉：两个拇指关节共享传感器，motor2无触觉。

构建方式为各工程目录 `cmake --build --preset Debug`。本轮三个工程均需配套烧录；只更新其中一块会发生新旧寄存器布局不一致。编译结果与警告在交付时说明，未进行自动化或硬件测试，不自动提交推送。
