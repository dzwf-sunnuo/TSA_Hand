# Modbus 步进电机定点位置模式使用指南

## 1. 适用范围

本文说明如何使用 `tools/stepper_angle_controller.py` 控制驱动器的 Modbus RTU 定点位置模式。驱动器手册覆盖 YL20M、YL28M、YL35M 和 YL42M；使用其他型号前，应先核对端子定义、供电范围和寄存器表是否一致。

本程序实现两种角度来源：

- 串口跟随：从独立串口逐行接收 `0.00\n`～`90.00\n` 的 ASCII 角度数据；
- 手动调试：不需要角度输入串口，可在界面中输入或选择角度后单次发送。

两种模式都把 `0.00°～90.00°` 映射为驱动器内部位置 `500～90000` 步。程序固定使用 `200.0 rpm` 和 `250 ms` 加速时间。由于当前电机没有编码器，程序不写容错误差寄存器。

串口跟随模式默认启用 `2.00°` 死区，手动调试模式不受死区限制。

> `500～90000` 是驱动器内部步数坐标，不等同于机械毫米数，也不会自动寻找机械零点。首次使用前应确认电机方向、机构零点、丝杆传动关系和可用行程。

## 2. 接线与上电前检查

### 2.1 驱动器和电机

断电完成所有接线：

1. 将两相四线步进电机的两组绕组分别接到驱动器 `A+ / A-` 和 `B+ / B-`。不要只按线色猜测绕组，可用万用表确认同一绕组的两根线。
2. 将直流电源正极接驱动器电源正端，电源负极接驱动器 `GND`。手册所列 YL 系列输入电压为 `4.7～30 V`，实际电压和电流容量还必须符合所用电机及具体驱动板规格。
3. 首次试机先脱开负载，或确保丝杆两端保留足够安全行程。

禁止带电插拔电机线。电机绕组接错、运行时断线或电源极性接反，都可能损坏驱动器。

### 2.2 RS485

电脑需要一个 USB 转 RS485 适配器：

| USB-RS485 端 | 驱动器端 |
|---|---|
| `A` 或 `D+` | `RS485D+` |
| `B` 或 `D-` | `RS485D-` |
| `GND` | `GND` |

建议通信双方共地。不要用 USB-RS485 适配器的电源脚给电机或驱动器主电源供电。若一直没有响应，可在断电后核对 A/B 标注；不同厂商对 A/B 命名可能相反，确认无误后再尝试交换两根差分线。

同一条 RS485 总线可以挂接多个从站，但每个从站地址必须唯一。长线或干扰环境应采用双绞线、合理布置总线两端终端电阻，并避免星形分支。

### 2.3 角度输入串口

串口跟随模式还需要另一个独立串口。角度设备和驱动器不能选择同一个 COM 口。角度设备每行发送一个 ASCII 数字，必须恰好带两位小数，例如：

```text
0.00
37.25
90.00
```

可使用 `\n` 或 `\r\n` 结束一行。空行、乱码、`NaN`、无穷值、非两位小数以及超出 `0.00～90.00` 的值都会被忽略，不会产生电机指令。

## 3. 通信参数和 Modbus RTU 基础

驱动器手册的默认通信配置为：

| 项目 | 值 |
|---|---:|
| 波特率 | `115200 bit/s` |
| 起始位 | 1 位 |
| 数据位 | 8 位 |
| 校验位 | 无 |
| 停止位 | 1 位 |
| 默认从站地址 | `1` |

即通常所说的 `115200、8N1`。上位机界面默认采用相同参数，并允许设置 `1～254` 的从站地址。

手册定义了三个功能码：

| 功能码 | 用途 |
|---:|---|
| `0x03` | 读取一个或多个保持寄存器 |
| `0x06` | 写入一个保持寄存器 |
| `0x10` | 连续写入多个保持寄存器 |

每个寄存器为 16 位，报文中的多字节数值按高字节在前排列。每帧末尾是标准 Modbus CRC16，初值为 `0xFFFF`、多项式为 `0xA001`，线上发送顺序为 **CRC 低字节在前、高字节在后**。相邻 Modbus RTU 帧之间应留出至少 3.5 个字符时间；本程序采用一问一答方式串行访问总线，不会同时发出多个未完成请求。

## 4. 定点位置模式寄存器

| 地址 | 含义 | 单位或编码 | 本程序写入值 |
|---:|---|---|---:|
| `0x0010` | 目标步数高 16 位 | 32 位目标步数的高字 | 随角度变化 |
| `0x0011` | 目标步数低 16 位 | 32 位目标步数的低字 | 随角度变化 |
| `0x0012` | 保留 | 应写 `0` | `0` |
| `0x0013` | 速度 | `0.1 rpm` | `2000`，即 `200.0 rpm` |
| `0x0014` | 加速时间 | ms | `250` |
| `0x0015` | 容错误差 | 步，仅启用编码器时有效 | **不写入** |

目标步数由 `0x0010` 和 `0x0011` 拼成 32 位数：

```text
target_step = (register_0x0010 << 16) | register_0x0011
```

手册允许用 32 位补码表达负步数，但本程序只发送 `500～90000` 的正数。`0x0015` 的含义是编码器反馈的容错误差，单位是步，不是角度精度；没有编码器时不需要配置。

手册中的定点模式示例从 `0x0010` 连续写 6 个寄存器，因此会同时写到 `0x0015`。本程序从 `0x0010` 只写 **5 个寄存器**，到 `0x0014` 为止，避免修改不需要的编码器参数。

## 5. 角度到步数的映射

程序采用端点精确的线性映射，并按常规四舍五入得到整数步数：

```text
target_step = round_half_up(500 + angle / 90 × (90000 - 500))
```

典型结果如下：

| 输入角度 | 目标步数 |
|---:|---:|
| `0.00°` | `500` |
| `45.00°` | `45250` |
| `90.00°` | `90000` |

映射结果最终限制在 `500～90000`。相同目标步数在上一次发送成功后不会重复发送；当角度数据到达速度高于驱动器处理速度时，程序只保留最新的有效目标，避免旧指令排队。

## 6. 标准报文

以下报文均假设从站地址为 `1`，并已包含 CRC。

### 6.1 发送 500 步（对应 0°）

```text
01 10 00 10 00 05 0A 00 00 01 F4 00 00 07 D0 00 FA E4 E5
```

字段含义：从 `0x0010` 起写 5 个寄存器、数据区 10 字节；目标步数为 `0x000001F4`，保留值为 `0`，速度为 `0x07D0`，加速时间为 `0x00FA`，CRC 为 `E4 E5`。

### 6.2 发送 90000 步（对应 90°）

```text
01 10 00 10 00 05 0A 00 01 5F 90 00 00 07 D0 00 FA 48 03
```

目标步数 `90000` 的十六进制值为 `0x00015F90`，CRC 为 `48 03`。

### 6.3 定点位置命令成功响应

```text
01 10 00 10 00 05 01 CF
```

响应回显从站地址 `01`、功能码 `10`、起始地址 `0010` 和寄存器数量 `0005`；CRC 为 `01 CF`。它表示驱动器已经接受寄存器写入，不代表机械机构已经到达目标位置。

### 6.4 急停请求与响应

本程序使用功能码 `0x06` 向寄存器 `0x0004` 写入 `1`：

```text
请求：01 06 00 04 00 01 09 CB
响应：01 06 00 04 00 01 09 CB
```

`0x06` 正常响应会原样回显请求。点击界面的“电机急停”后，程序会先停止串口跟随并清空尚未发送的目标，再发送急停请求，避免下一条角度立即重新启动电机。

## 7. 安装与启动

需要 Python 3.10 或更高版本。Windows 官方 Python 通常已经包含 Tkinter；额外安装串口库：

```powershell
python -m pip install pyserial
```

如需运行自动测试，再安装 pytest：

```powershell
python -m pip install pytest
```

在项目根目录启动程序：

```powershell
python tools/stepper_angle_controller.py
```

如果 `python` 命令不可用，可在 Windows 上尝试把上述命令中的 `python` 替换为 `py -3`。

## 8. 手动调试模式

建议首次连接按以下顺序测试：

1. 保持电机脱载，或确认机构在两个方向都有足够行程；打开驱动器电源。
2. 启动上位机，点击“刷新串口”，选择 USB-RS485 对应的“驱动串口”。
3. 选择“手动调试模式”，保持波特率 `115200`，填写实际 Modbus 地址，默认是 `1`。角度串口可以留空。
4. 点击“连接”，等待状态区显示“驱动串口连接成功”。
5. 先输入或选择一个中间角度，例如 `45.00°`。输入框、滑块和快捷按钮只更新预览，不会立即驱动电机。
6. 核对预览步数为 `45250`，再点击“发送角度”。观察发送帧和响应帧。
7. 确认转动方向和机构运动方向正确后，再逐步尝试靠近 `0°` 或 `90°`，不要第一次测试就直接运行到端点。

点击“停止跟随”只对串口跟随模式有效，不会中止已经开始的电机运动。遇到危险运动时，应点击“电机急停”，并在必要时切断驱动器动力电源。

## 9. 串口跟随模式

1. 先确认角度设备持续输出类似 `45.00\n` 的完整行，波特率也是 `115200、8N1`。
2. 在界面中选择不同的“驱动串口”和“角度串口”，选择“串口跟随模式”。
3. 设置正确的 Modbus 地址，并在“跟随死区”中填写 `0.00～90.00°`；默认值为 `2.00°`，填写 `0` 可关闭死区。
4. 点击“连接”。若最初以手动模式连接，也可随后切换到串口跟随模式、选择角度串口，再点击“开始跟随”。
5. 点击“开始跟随”。状态区会显示原始数据、有效角度、映射步数和最近响应。跟随期间死区输入框会被锁定，停止跟随后可重新设置。
6. 点击“停止跟随”可停止读取角度和发送新位置，但不会向驱动器发送急停，也不会改变当前运动状态。
7. 点击“断开”会先停止跟随，再关闭两个串口；断开和关闭窗口都不会隐式发送急停。

若收到非法行，日志会显示“忽略非法角度数据”，电机保持上一个有效目标。有效数据输入过快时，中间目标可能被新目标覆盖，这是为了降低控制延迟而设计的正常行为。

### 跟随死区规则

- 每次开始跟随后，第一条有效角度始终发送。
- 驱动器返回正确的 Modbus 响应后，该角度成为死区比较基准。
- 新角度与基准角度之差小于或等于死区时，不发送位置命令；日志显示“死区内忽略”。
- 差值大于死区时发送新位置，成功响应后更新基准。
- 通信失败不会更新基准。
- 死区只作用于串口跟随，手动点击“发送角度”始终发送，不受死区限制。

例如死区为 `2.00°`，成功发送的基准为 `10.00°` 时，`11.00°` 和 `12.00°` 不会改变电机目标；收到 `12.01°` 时才发送新位置。

## 10. 日志说明

| 日志内容 | 含义与处理 |
|---|---|
| `发送位置命令：...` | 已向驱动器发送完整 `0x10` 报文 |
| `收到位置响应：...` | 响应的地址、功能码、起始地址、数量和 CRC 均通过校验 |
| `发送急停命令：...` | 已发送 `0x06` 急停请求 |
| `收到急停响应：...` | 急停回显和 CRC 均通过校验 |
| `忽略非法角度数据：...` | 该行格式或范围不合法，没有发送位置指令 |
| `CRC校验失败` | 收到报文，但 CRC 不正确；检查干扰、接地、波特率和 A/B 接线 |
| `响应超时` | 在规定时间内没有收到完整响应；检查端口、地址、供电、接线和串口占用 |
| `位置命令失败，正在重试` | 位置命令第一次失败，程序自动再发送一次 |
| `位置命令重试失败` | 第二次仍失败，本次目标未确认成功 |
| `死区内忽略` | 当前跟随角度与最近成功角度的差值未超过设定死区，因此没有发送位置命令 |
| `Modbus异常响应` | 驱动器明确拒绝请求，查看异常码 |

手册定义的异常码为：

| 异常码 | 含义 |
|---:|---|
| `0x01` | 功能码错误 |
| `0x02` | 地址错误 |
| `0x03` | 长度错误 |

位置命令在超时、CRC 错误或字段不匹配时最多自动重试一次。急停命令不会自动重试；如果急停通信失败，应立即采取硬件断电等安全措施，而不是依赖软件继续尝试。

## 11. 常见故障排查

### 无法打开串口

- 点击“刷新串口”，确认设备对应的 COM 口仍存在；
- 关闭串口助手或其他占用该 COM 口的软件；
- 检查 USB-RS485 驱动是否已正确安装；
- 确认角度串口和驱动串口没有选择为同一个端口。

### 一直响应超时

- 核对驱动器已上电且地址与界面一致；
- 核对两端都是 `115200、8N1`；
- 检查 `D+` 对 `D+`、`D-` 对 `D-` 和共地；
- 排除 A/B 命名相反、线缆过长、星形分支或缺少终端匹配的问题；
- 同一总线只保留一个 Modbus 主站，并确保从站地址不重复。

### 有响应但 CRC 经常错误

- 缩短线缆，使用双绞线并远离电机动力线；
- 检查共地、屏蔽和总线终端；
- 确认没有两个主站同时发报文；
- 不要把十六进制文本字符串直接发送给驱动器，实际串口必须发送对应的二进制字节。

### 电机方向或位置不符合预期

- 先急停并断开动力，检查两相绕组分组是否正确；
- 重新确认机构零点以及 `500～90000` 与机械行程的标定关系；
- 在小范围、中间位置低风险验证方向后，再扩大运动范围；
- 不要把容错误差当作角度精度；本程序没有写入该编码器参数。

## 12. 安全注意事项

1. 第一次调试必须先脱开负载，或保证全行程内没有人员、线缆和硬限位干涉。
2. 先测试中间角度和小范围运动，确认方向正确后再接近端点。
3. 软件“停止跟随”和“断开”都不是急停；它们不会保证立即停止正在执行的运动。
4. 软件急停依赖电脑、USB、RS485 和驱动器均正常。对可能造成人身或设备损伤的机构，应另设独立硬件急停和限位保护。
5. 关闭窗口不会自动急停。离开设备前应先确认电机静止，再按现场安全流程断开动力电源。
6. 不要在机构运动时带电插拔电机、电源或通信接头。
