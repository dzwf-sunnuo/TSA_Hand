# 七电机独立模式改造实施计划

目标：主板用14个16位保持寄存器表达七路目标及各自模式，拆分为一号从板8寄存器、二号从板6寄存器。用户已经明确同意同步修改主板。

结构：每路交错排列目标和模式；模式高字节及目标编码沿用现有1/3/4/5/6/7定义，低字节为各路使能。二号板停用原motor0，原motor1～3硬件编号、ADC标定、CAN顺序和采集位不改变。

约束：保留工作区已有未提交的ADC、CAN、UART4修改；不提交或推送；中文注释；仅做固件编译，不执行其他测试、不烧录。

- [x] 两从板新增每路寄存器宏、原子命令快照及独立模式事件，PID迁到0x20～0x28。
- [x] 电机闭环改为逐路模式，独立清理PID、导纳状态与超力锁定；同模式双拇指保留顺序退让，混合模式独立计算。
- [x] 二号板所有启动、调度、掉电恢复输出路径跳过原motor0；保持三指原硬件映射。
- [x] 主板Reg[4..17]作为手指14寄存器，原Reg[14..17]配置迁到Reg[40..43]；扩大下游缓冲，分发8/6寄存器。
- [x] 旧CAN动作、预设动作在专用适配层转换旧目标/公共模式；UART4入口复用新主板寄存器。
- [x] 更新三工程协议说明及示例CRC，编译三个Debug固件并报告结果，不执行自动/硬件测试。

编译记录：三个Debug固件均链接成功；主板还生成BIN/HEX。一号板已有监控任务的嵌套注释、未使用变量警告保留，本轮未修改该文件。主板首次构建的objcopy路径缺失，通过本次进程PATH加入本机工具链后完整构建成功。
